 Superstore Sales & Profitability Analysis

📌 Project Overview

This project analyzes Superstore sales data to understand sales performance, profitability, customer performance, regional trends, and product-level performance.

The project was completed using "SQL and Power BI".

 🛠️ Tools Used

- SQL
- Power BI
- Excel / CSV

📊 Key Analysis

- Total Sales and Total Profit
- Total Orders and Average Sales
- Sales and Profit by Category
- Sales by Region
- Yearly Sales and Profit Trends
- Top 5 Sub-Categories by Sales
- Top Customers by Sales and Profit
- Top and Bottom Performing Sub-Categories

 📈 Power BI Dashboard

The dashboard includes KPI cards and interactive visualizations for analyzing sales and profitability across categories, regions, years, and sub-categories.

 Key Insights

- Technology generated the highest total sales and profit among the three categories.
- West region recorded the highest sales.
- Sales increased significantly in 2025 and 2026.
- Tables was the largest loss-making sub-category.
- Copiers generated the highest total profit among sub-categories.

 📁 Project Files

- `samplesuperstore.csv` – cleaned dataset
- `Superstore_Sales_Analysis.pbix` – Power BI dashboard
- `SQL_Queries.sql` – SQL analysis queries
